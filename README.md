# Trackaa 2.0 — The All-in-One Operating System for Early-Stage Startup Founders

Trackaa unifies the foundational operational workflows of a startup into a single, cohesive hub:

- **Execution Engine**: Daily tasks with intelligent date grouping (Today, Overdue, Upcoming), assignee capacity indicators, and blocker resolutions with institutional audit narratives.
- **Founder Asset Vault**: Permanent secure vault for SAFE notes, investor pitch decks, brand vector kits, PRDs, and essential hyperlinks.
- **Startup Finance & Runway Hub**: Lightweight cash accounting (Capital In vs. Operational Burn, dynamic 30-day runway projection, and receipt attachments).
- **Customer Discovery**: Structured interview logging with stakeholder roles, founder insights, verbatim client notes, and multi-file attachment evidence (up to 5 documents/screenshots).
- **Apple-Inspired Design Language**: Translucent glassmorphism (`backdrop-blur-2xl`), deep space obsidian navy (`#0A111E`), vibrant action green (`#00C389` / `#10B981`), and uncluttered layouts.

---

## Getting Started

### 1. Development Server
```bash
npm run dev
```
Runs the local development server at `http://localhost:5173`.

### 2. Production Build
```bash
npm run build
```
Typechecks with `tsc` and bundles for production via `vite`.

### 3. Preview Production Build
```bash
npm run preview
```
